# Duda Somma Doces

Loja preparada para Netlify.

## Publicar

No Netlify, escolha **Import an existing project → GitHub → excession17/duda-somma-doces**.

- Branch: `main`
- Build: `npm run build`
- Publicação: `dist`
- Funções: `netlify/functions`

O arquivo `netlify.toml` configura a publicação automaticamente. Após publicar, ative **Identity** no painel do Netlify para habilitar cadastro e login por e-mail.

Veja [LEIA-ME.md](LEIA-ME.md) para instruções e conferência dos pedidos.
